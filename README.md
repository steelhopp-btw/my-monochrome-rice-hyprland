# 🖤 Hyprland Monochrome Dotfiles

Минималистичная монохромная конфигурация Hyprland для Arch Linux. Только черный, белый и оттенки серого для максимального фокуса и чистой эстетики.

## 🛠️ Основные компоненты

* **WM:** Hyprland
* **OS:** Arch Linux
* **Shell:** Fish
* **Terminal:** / Alacritty
* **Bar:** Waybar
* **Launcher:** Rofi
* 
## 🚀 Установка

### 1. Подготовка системы
Убедись, что у тебя установлен Arch Linux и базовые зависимости для работы Wayland.

### 2. Клонирование репозитория
```bash
git clone https://github.com/steelhopp-btw/my-monochrome-rice-hyprland.git
cd my-monochrome-rice-hyprland
```

### 3. Копирование конфигурационных файлов
Перед копированием рекомендуется сделать бэкап твоих старых конфигов!
```bash
cp -r config/* ~/.config/
```

## ⌨️ Основные горячие клавиши

* `Mod` + `Enter` — Открыть терминал
* `Mod` + `Q` — Закрыть окно
* `Mod` + `space` — Запустить меню приложений (Rofi/Wofi)
* `Mod` + `M` — Выйти из Hyprland
